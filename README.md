# JVS — Jyosna's Versatile Stability

Professional Blue & Black responsive website based on the supplied JVS brochure.

## Run locally

No framework is required.

1. Keep `index.html`, `styles.css`, and `script.js` in the same folder.
2. Open `index.html` in Chrome/Edge.
3. For a better development experience, use VS Code + Live Server.

## Deploy

You can upload the three files to GitHub Pages, Netlify, Vercel, or any normal web hosting.

## Notes

- Content is based on the brochure supplied for the task.
- Contact details shown in the brochure were used.
- Replace/optimise the placeholder visual cards with official brand photos/logos if the organisation provides them.
